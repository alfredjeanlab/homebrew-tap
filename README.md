# Homebrew Tap

Homebrew formulas for Alfred Jean tools.

## Installation

```bash
brew tap alfredjeanlab/tap
```

## Formulas

### trucker

Shares compiled crates between worktrees as a rustc wrapper.

```bash
brew install alfredjeanlab/tap/trucker
```

### ripcloc

Quickly counts lines of code by language.

```bash
brew install alfredjeanlab/tap/ripcloc
```

### claudeless

A Claude CLI simulator for integration testing.

```bash
brew install alfredjeanlab/tap/claudeless
```
